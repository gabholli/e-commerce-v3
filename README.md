# Project Title
React Shop

## Description
I built this mock e-commerce app using the following:

- React Router 7
- Tailwind CSS
- Node.js
- Express.js
- MongoDB

## Getting Started
### Dependencies
- Runs within one's web browser of choice
### Installing
- This web page does not require any direct installation on your computer
### Executing program
- To execute, navigate within your web browser to https://gabholli-e-commerce-site.netlify.app
